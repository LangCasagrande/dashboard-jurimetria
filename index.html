Como funciona

Do CNJ ao painel, todo dia

A API do CNJ não pode ser chamada direto do navegador e é lenta, então os números são calculados antes.

1

Coleta automática

Toda madrugada, um coletor em Python consulta a API Pública do DataJud para os 91 tribunais, com novas tentativas quando ela está sobrecarregada.

2

Estatísticas prontas

As contagens por classe, assunto, órgão, grau e data viram arquivos JSON salvos no repositório, com o histórico de cada coleta.

3

Painel aberto

O site lê esses arquivos e desenha os gráficos na hora, sem servidor, com versão em tabela e dados para baixar.
